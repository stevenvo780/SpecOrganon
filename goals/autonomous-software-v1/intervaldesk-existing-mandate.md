# Mandato existente para IntervalDesk

El dueño pidió preparar pruebas reales con Codex/MCP/Docker, alcanzar una
validación autónoma con un proyecto pequeño, asignar la goal y publicar sus
resultados en su web existente. El objetivo activo incluye un caso nuevo con
nueve fases, controles adversos, comparación prospectiva N/S/T de varios tipos
y dos familias de modelos, ablación, instalación reproducible y publicación.

IntervalDesk es una selección técnica delegada a Codex dentro de ese alcance;
el dueño no eligió personalmente esa tarea ni su arquitectura. La revisión
separada evalúa conformidad con este mandato. Una aprobación local conserva
esa delegación con la etiqueta declarativa del dueño, sin autenticar identidad
ni inventar consentimiento nuevo.

Se conservan el intento inconcluso LogLens, el GOAL original, los treinta inputs
congelados y todos los resultados del piloto backup. Usar sólo proveedores y
perfiles originales autorizados; no copiar credenciales/sesiones, cambiar de
cuenta para eludir fallos ni contratar servicios. Un programa o una fase aceptada
no demuestran superioridad metodológica ni el objetivo alimentario de campo.
