# Mandato técnico delegado para desarrollo T

El operador autorizó mejorar SpecOrganon, pruebas reales con sus proveedores
existentes y publicación íntegra de resultados, fallos y límites. Codex organiza
las elecciones técnicas dentro de ese alcance; no afirma que el operador haya
elegido personalmente cada solución. Este mandato registra esa autorización.

Resolver cada contrato público registrado conservando las nueve fases
sustantivas, normas y fines explícitos, hipótesis comprobables, observaciones con
fuente, alternativas comparables, requisitos trazables, implementación utilizable,
documentación necesaria, batería fijada antes de medir y validación contrastada.
Autor y revisión técnica usan invocaciones independientes con custodia verificable.

Solo leer contexto proporcionado y escribir entrega propia en el runtime
registrado. Sin copiar credenciales, cambiar cuenta por fallos, acceder a datos
reservados, importar generaciones anteriores, cambiar baterías/criterios para
hacerlos pasar, inventar hechos de campo ni invocar proveedores retirados.
Las reparaciones consumen el presupuesto original y conservan su historia.

Una revisión local delegada valida conformidad técnica con este mandato; no
autentica al operador ni crea aprobación humana inexistente. Un conflicto de
valor fuera del mandato conserva el pendiente. Las pruebas públicas y auditorías
de desarrollo no prueban superioridad ni verdad externa del método.
