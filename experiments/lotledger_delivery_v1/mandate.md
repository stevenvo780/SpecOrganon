# Mandato delegado LotLedger

El operador autorizó lograr la goal de software autónomo reproducible y publicarla.
Elegir contrato/arquitectura dentro de este alcance es decisión técnica delegada.
Crear una CLI local para movimientos por lote/ubicación, sin datos de personas,
red ni efectos externos, respetando el contrato previo y todos los límites.
Una sola identidad y resultado conservado aunque falle. No ampliar presupuesto,
retocar reservados tras respuestas, inventar evidencia/consentimiento o repetir
hasta una victoria. Conformidad de un revisor separado registra la delegación;
no atribuir al dueño una elección personal ni autenticarlo por una etiqueta local.
Las normas deben proteger integridad/idempotencia y declarar el alcance técnico.
El éxito funcional no prueba utilidad humana, campo ni superioridad metodológica.
