# Mandato existente del operador para las celdas de software

El operador pidió completar una versión autónoma y reproducible de SpecOrganon
y evaluar proyectos pequeños nuevos sin intervención humana rutinaria. Autoriza
la construcción local de RoutePlan/TreeMap según sus contratos, pruebas aisladas
y revisión separada con sus proveedores existentes. Las decisiones técnicas
dentro de ese alcance están delegadas; no afirmar que las eligió personalmente.

Priorizar corrección, trazabilidad, documentación útil y evidencia real. No
inventar mediciones, consentimiento o beneficios de campo. Comparar alternativas
sustantivas, incluida una alternativa sin software cuando proceda. Un nuevo
conflicto de valor fuera del alcance autorizado no recibe aprobación automática.

No cambiar cuentas, copiar credenciales, contratar servicios ni ampliar límites
durante una celda. Conservar fallos y artefactos parciales; no repetir casos hasta
ganar. No usar feedback reservado para reparar. Preservar el piloto anterior y
GOAL.md original. La etiqueta human:owner registra este mandato delegado local;
no autentica identidad o custodia. Este documento no aprueba decisiones aún no
propuestas ni constituye prerregistro del estudio.
